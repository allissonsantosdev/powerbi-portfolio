## 🛠️ Tecnologias e Habilidades Demonstradas

* **Ferramenta Principal:** Microsoft Power BI Desktop
* **Linguagens e Expressões:** DAX (Data Analysis Expressions) e Linguagem M (Power Query)
* **Modelagem de Dados:** Tratamento de dados, relacionamentos e hierarquias temporais
* **UI/UX para Dashboards:** Design limpo, temas harmoniosos, cartões modernos e contraste acessível
* **Recursos Avançados:** *Decomposition Tree*, Tooltip Pages, Mobile Layout e Custom Visuals

## 💻 Como Explorar os Arquivos Localmente

1. Clone o repositório em sua máquina:
   ```bash
   git clone https://github.com/allissonsantosdev/powerbi-portfolio.git
   ```
2. Instale ou abra o **Power BI Desktop**.
3. Navegue até a pasta do projeto desejado e abra o respectivo arquivo `.pbix`.
